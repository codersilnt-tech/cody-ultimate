# 🚀 Cody Ultimate (v3.0)

أداة **Cody Ultimate** لإدارة وتنفيذ المهام البرمجية عبر سطر الأوامر في بيئة Termux وأنظمة Linux.

## 📥 طريقة التثبيت والتشغيل

انسخ الأوامر التالية والصقها في تطبيق **Termux**:

```bash
git clone https://github.com
cd cody-ultimate
chmod +x cody.sh
./cody.sh
```

## 📁 هيكل المشروع
- `cody.sh`: الملف التنفيذي الرئيسي للأداة.
- `cody_modules/`: مجلد الوحدات والإضافات البرمجية.
